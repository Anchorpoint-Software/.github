# Anchorpoint

**Version control for artists, designers and engineers who work with large files**

## What is Anchorpoint

Anchorpoint is a version control solution for large 3D, design and media files. It is built for teams where non-developers such as artists, designers, architects and engineers work alongside developers. Anchorpoint is fully compatible with Git and Lore and adds what these systems lack for binary-heavy projects: file locking, automatic Git LFS configuration, visual previews, review workflows and metadata.

Anchorpoint is used by over 200 companies worldwide and is developed by Anchorpoint Software GmbH in Koblenz, Germany.

With Anchorpoint you can:
- Commit, pull and push files with Git, with Git LFS configured automatically for binary files
- Lock files to prevent conflicting edits on files that cannot be merged
- Browse project files visually with thumbnails and previews
- Tag, comment on, review and approve files
- Check out only the parts of a large repository you need
- Use templates and folder conventions to keep projects organized
- Work with Unreal Engine and Unity, 3D DCC applications such as Blender and Maya, CAD tools such as SolidWorks and any other application that works with large binary files

Anchorpoint can also be used as an alternative to a DAM for game developers and to a PDM system for engineering workflows.

## Why Anchorpoint

- **No lock-in**: Your files stay on the server you choose, such as GitHub, GitLab, Azure DevOps, Gitea, a self-hosted Git server or a Lore server. Anchorpoint only stores metadata.
- **Simple over complex**: Built for people who are not version control experts, while technical users keep full Git compatibility.
- **Built for large projects**: Handles terabyte-scale repositories, supports selective checkout and cleans up Git LFS caches to reduce local storage.
- **Continuous updates**: We ship monthly updates with new features and UX improvements.

## Getting Started

1. **Download** Anchorpoint for Windows or macOS from [anchorpoint.app](https://www.anchorpoint.app) and start your free trial.

3. Create or join a repository, enable file locking or selective checkout as needed, and invite your team.
4. Join our [Discord](https://discord.com/invite/ZPyPzvx) for support, feedback and updates.

## Integration & Extensibility

- Unreal Engine and Unity plugins for file locking and commits from inside the engine
- Python API and Actions to automate tasks such as renaming, publishing or file conversions
- Works with existing Git workflows: developers can keep using their usual Git tools alongside Anchorpoint
