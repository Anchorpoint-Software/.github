# Anchorpoint

**Version control & asset management for artists**

## What is Anchorpoint

Anchorpoint is a version control tool built for artists, animators, game developers, and creative teams. It extends Git to better handle large binary assets, review workflows, and metadata, while keeping the simplicity of a visual file browser.

With Anchorpoint you can:  
- Commit, pull, push files with Git + LFS handling  
- Use file locking to prevent conflicting edits  
- Browse assets visually (thumbnails, previews)  
- Tag, comment, review, and approve assets  
- Use templates and folder conventions to organize assets
- Integrate with Unity, Unreal, other DCCs such as Blender and Maya via plugins or API
  

## Why Anchorpoint

- **No lock-in**: You always maintain control over your production data; Anchorpoint only stores metadata.
- **Simple over complex**: We prioritize ease of use, especially for non-technical users.
- **Built for realtime projects**: Handles TB-scale assets, sparse checkout, and cleans up Git LFS caches to reduce storage overhead. 
- **Continuous updates**: We ship monthly updates with new features and UX improvements.



## Getting Started

1. **Download** Anchorpoint for your platform (Windows/macOS) and start your free trial.
2. Consult our [Documentation & Tutorials](https://docs.anchorpoint.app) for detailed setup, Git workflows, integrations, API, self-hosting, and more.
3. Join our Discord or community channels for support, feedback, and updates.  
4. Start by creating or joining a repository, enabling file locking or selective checkout as needed, and onboarding your team.



## Integration & Extensibility

- Unity and Unreal Engine plugins for native file locking and commits.
- Python API and “Actions” system to automate tasks (e.g. renaming, publishing, conversions)
- It plays nicely with existing Git workflows: you can still use other Git clients if you don’t rely on Anchorpoint-exclusive features.
